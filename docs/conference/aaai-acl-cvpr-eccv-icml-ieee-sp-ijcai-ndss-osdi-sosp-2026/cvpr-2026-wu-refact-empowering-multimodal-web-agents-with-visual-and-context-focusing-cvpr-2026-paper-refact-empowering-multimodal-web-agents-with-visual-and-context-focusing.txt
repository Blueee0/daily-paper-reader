Abstract
Multimodal Web Search Agents demonstrate a practically
valuable capability by fusing information from diverse
modalities (e.g., text and vision), retrieved iteratively from
the internet, to address complex user queries. However, the
visual modality is prone to information overload, and the
noise contained within it—such as irrelevant background
details or complex structures—can disrupt the model’s at-
tention, misdirecting its operational focus toward an er-
roneous path.
To address the aforementioned challenge,
we propose ReFAct (Reasoning, Focusing, and Acting), a
novel framework that empowers the agent to actively man-
age its cross-modal context. This allows the agent to adjust
its operational focus, thereby mitigating the impact of noise
on multimodal Web Search Agents.
Specifically, ReFAct
employs a Grounding tool for active visual perception to
dynamically filter information.
We also design external
memory-based Defocus/Refocus operations for selective in-
formation retention, further modulating information density
within the multimodal context. Ultimately, this ensures the
agent maintains focus during problem-solving. To evaluate
and enhance agent capabilities in complex and noisy multi-
modal contexts, we first propose a pipeline for constructing
datasets with flexible complexity. We introduce a new open-
source benchmark: GroundedVQA. Finally, we experimen-
tally demonstrate the effectiveness of our proposed method
on GroundedVQA and other widely-used benchmarks.

2. Related Work
2.1. Multimodal LLMs
Multimodal Large Language Models (MLLMs) have
emerged as a dominant paradigm for general-purpose vi-
sual understanding. By bridging powerful visual encoders
(e.g., CLIP[15], SigLIP[21]) with large language models
[10, 11, 22], MLLMs such as GPT-5 [14], Gemini [5], and
the Qwen-VL series [1] have demonstrated remarkable ca-
pabilities in tasks ranging from visual captioning to com-
plex reasoning. Despite their success on static benchmarks,
standard MLLMs face two critical limitations when applied
to real-world scenarios. First, they operate under a closed-
world assumption, relying solely on parametric knowledge
that quickly becomes outdated, rendering them unsuitable
for dynamic information seeking. Second, they typically
employ a passive perception mechanism, where the entire
image is encoded into visual tokens regardless of task rele-
vance. In highly cluttered realistic environments (e.g., com-
plex web pages), this leads to severe attention dilution and
increased hallucination [18], as the model struggles to dis-
tinguish core evidence from background noise.
2.2. Multimodal Web Search Agents
To address the static knowledge limitation, recent research
has focused on developing Web Search Agents capable
of autonomous information gathering. Early efforts were
predominantly text-centric.
Search-R1 [8] and DeepRe-
searcher [23] successfully integrated LLMs with search en-
gine APIs, employing iterative “Reason-then-Act” loops to
solve complex textual queries. Recognizing that the real
web is inherently visual, the field is rapidly shifting towards
Multimodal Web Search Agents. Pioneering works such
as WebWatcher [4] and MMSearch-R1 [19] have equipped
MLLMs with tools to search rich web environments, per-
forming actions like image searching and webpage retrieval.
However, these multimodal agents largely inherit the
passive perception limitation of their base MLLMs. They
typically process raw, full-page screenshots or complete
search result pages. As highlighted by recent studies [6, 18],
this includes both visual noise (e.g., irrelevant backgrounds,
complex textures) and retrieval noise (e.g., advertisements,
navigation bars) from raw webpages. This passive intake
can establish a “false factual basis” from images or cause
the agent to be “drowned” in irrelevant text during reason-
ing. GUI agents such as GUI-R1 [12] target action execu-
tion (e.g., clicking, navigation), a different paradigm from
our retrieval and reasoning focus. In contrast, our ReFAct
framework actively manages cross-modal context: counter-
ing visual noise via an active Grounding tool, and manag-
ing retrieval noise through Defocus/Refocus operations for
selective working memory control, which are absent in ex-
isting agents.
3. Methodology
In this section, we present the ReFAct framework, a novel
paradigm designed to equip multimodal web search agents
with active context management capabilities. By unifying

information filtering through a central concept of “active fo-

and retrieval noise that plague existing agents.
3.1. The ReFAct Framework
We formalize the agent’s interaction with the multimodal
web environment as a sequential decision-making process.
At each step t, the agent observes a state ot and maintains
a context history Ht. Unlike standard agents that passively
accumulate all observations into Ht, ReFAct empowers the
agent to actively curate its context through explicit Focusing
actions. This expands the traditional action space to include
actively managing both visual attention and working mem-
ory load.
Visual Focusing. To combat visual noise arising from com-
plex backgrounds that often mislead image retrieval sys-
tems, ReFAct introduces an active Grounding mechanism.
Instead of passively using entire images for search queries,
the agent can explicitly select high-relevance regions.
Specifically, before executing an image-based search, the
agent can generate a grounding action Ground(It, bbox),
where bbox = [x1, y1, x2, y2] specifies the target crop co-
ordinates. The environment then uses this cropped region
It[bbox] as the precise query for subsequent retrieval tools
(e.g., reverse image search). Crucially, by having the agent
directly predict bounding boxes, we avoid introducing ex-
ternal biases from third-party detection models and allow
the grounding capability to be jointly optimized with the
agent’s reasoning process during training.
Memory Focusing. To effectively manage retrieval noise
from cluttered webpages and prevent context exhaustion
over long horizons, ReFAct implements a dual-memory sys-
tem. We distinguish between a limited, high-value active
working memory (Ht) and an unlimited external memory
(Mt). Two complementary tools govern the flow between
them:
• Defocus: When the agent encounters information-dense
but currently non-critical content (e.g., full text of a
lengthy article), it can actively defocus. This action of-
floads the raw content to Mt while retaining only a con-
cise, evidence-bearing summary and a unique reference
ID in Ht, keeping the context clean for immediate rea-
soning.
• Refocus:
Conversely, when subsequent reasoning re-
quires details previously offloaded, the agent can exe-
cute Refocus(id). By referencing the specific ID from
the summary in Ht, it precisely retrieves the original raw
content from Mt, avoiding vague or error-prone fuzzy re-
trieval.

capabilities into a cohesive Reasoning, Focusing, and Act-
ing cycle. In each turn, the agent generates a thought rt to

To address this limitation, we introduce GroundedVQA,
a dataset designed for both training and evaluating agents in
high-noise visual environments. The distinguishing feature
of GroundedVQA is the mandatory requirement for visual
grounding: questions are constructed such that they can-
not be answered without first precisely localizing the rele-
vant image regions. This design not only provides a rigor-
ous benchmark for evaluating noise-filtering capabilities but
also serves as a high-quality supervision source for training
agents with active grounding skills.
To advance agents’ capabilities from basic entity ground-
ing to complex relational reasoning, GroundedVQA is
structured into two progressive difficulty levels:
Level 1: Focused Entity Reasoning. This level targets sin-
gle, non-salient entities in cluttered scenes. Successfully
answering these questions requires an effective composition
of perception, retrieval, and reasoning:
1. Visual Grounding: The agent must localize the specific
target entity referenced in the question (e.g., a small logo
on a product) amidst visual noise.
2. Precise Identification: Using the localized region as a
query, the agent must identify the entity’s fine-grained
category or specific model via image retrieval tools.
3. Knowledge Reasoning: The agent must use the identi-
fied entity name to query external knowledge bases and
derive the final answer.
Level 2: Cross-Entity Relational Reasoning. This level
increases complexity by requiring integrated reasoning
across multiple entities and diverse information sources:
1. Multi-Target Grounding: Localizing multiple distinct
entities mentioned or implied within the query.
2. Sequential Retrieval: Information must be retrieved
for each entity independently. This often necessitates
managing multiple retrieval contexts, potentially invok-
ing memory focusing mechanisms (Defocus/Refocus) to
avoid information overload.
3. Associative Reasoning: The final answer requires syn-
thesizing retrieved facts across entities, such as compar-
ing attributes (e.g., “Which of the two identified cars has
a higher top speed?”) or discovering latent relationships.
3.2.1. Construction Pipeline
To generate high-quality data that mandates visual ground-
ing, we designed a Region-based VQA Pipeline following a
“Construct-then-Sample” paradigm, which is visually out-
lined in Fig. 3. Leveraging the high-resolution and clutter-
rich scenes sampled from the SA-1B dataset[9], we first
construct a fine-grained “Image-Knowledge Graph”(i.e., an
image-centric knowledge graph) for each image. We then
sample subgraphs from this knowledge graph to automati-
cally generate Level 1 and Level 2 QA pairs.
Phase I: Image-Knowledge Graph Construction The in-
put image I serves as the root node of the knowledge graph
GI. We first employ Qwen3-VL-235B-A22B-Instruct to
detect candidate entities E = {e1, ..., eK} (e.g., logos,
landmarks) and generate a visual description vi for each ei.
Subsequently, each candidate entity ei is subjected to im-
age retrieval via the Google Serper API, yielding the top-10
results (image thumbnails and titles). To verify each can-
14993


didate, Qwen3-VL is again employed to analyze these re-
trieved results against the original ei. We apply a stringent
filtering process, retaining only entities identified with high
certainty and discarding all ambiguous results. These suc-
cessfully verified entities are termed Grounded Entities,
and their determined identity is si. These Grounded Enti-
ties are then connected to the root node I.The relationship
edge is populated with the visual description vi generated
during the initial detection step, representing the entity’s vi-
sual context within the image. In the next step, the textual
identity si of each Grounded Entity is used as a query for
the Google Search engine to retrieve external facts. We em-
ploy Jina Reader to parse the content of the top-5 returned
URLs, ensuring high-quality content extraction. This re-
trieved text is analyzed by an LLM to extract new entities,
termed Retrieved Entities, and to establish the semantic
relationships linking them to their corresponding Grounded
Entities. This expansion process is executed iteratively. In
each subsequent hop, a subset of newly discovered nodes
(e.g., Retrieved Entities) is randomly selected for further
expansion using the text-based retrieval and fact extraction
protocol. This iterative methodology enables the progres-
sive construction of a comprehensive knowledge graph GI
derived from the initial image.
Phase II: QA Generation.
We sample subgraphs from
GI and employ an LLM to convert them into QA pairs.
For Level 1, we sample a subgraph comprising a single
Grounded Entity, its associated external facts, and its cor-
responding visual description(e.g., “the phone in the upper
left corner”). For Level 2, we sample subgraphs involving
multiple Grounded Entities, their respective facts, and their
visual descriptions, enabling the synthesis of questions that
require comparative or associative reasoning. These sam-
pled subgraphs, crucially including the visual descriptions,
are then fed into an LLM. The model is prompted to gen-
erate a multi-hop question that anchors the query to the en-
tity’s visual description . The corresponding answer is syn-
thesized from the retrieved facts. This process ensures the
generated pairs are inherently visual, linking specific visual
context to external knowledge.
Phase III: Hybrid Verification. The generated data is split
into Training and Evaluation sets with distinct protocols.
For the training set, we prioritize scalability and retrieval-
necessity. We implement an automated rejection sampling
protocol using Qwen-2.5VL-32B. Specifically, each gener-
ated question is fed to this model without its correspond-
ing image.
If the model can answer the question cor-
rectly based solely on its internal parametric knowledge,
the sample is discarded.
This strategy filters out trivial
questions where the grounding-retrieval mechanism is re-
dundant. Conversely, the Evaluation Set undergoes rigor-
ous human verification. Verifiers explicitly discard “short-

3.3. Reinforcement Learning
We develop ReFAct-7B using an end-to-end Reinforcement
Learning (RL) stage, specifically designed to instill active
focusing strategies directly from environmental feedback.
It is worth noting that while our framework supports both
visual and memory focusing, our training phase primarily
targets active visual grounding. We prioritize this because
overcoming visual noise represents a more critical and fun-
damentally missing capability in current MLLMs. Further-
more, stabilizing RL training with highly dynamic context
changes (introduced by Defocus/Refocus) remains an open
challenge, so we focus our optimization resources on the
most impactful visual modality.
We employ GRPO to enable the model to emerge with
optimal grounding strategies (e.g., learning when cropping
is necessary vs. redundant). GRPO is particularly suitable
for training large multimodal models as it estimates base-
lines from a group of sampled trajectories for the same in-
put, eliminating the need for a separate, memory-intensive

4. Experiments
4.1. Experimental Setup
Implementation Details.
We utilize Qwen2.5-VL-7B-
Instruct as our base model. The model is trained using the
GRPO algorithm to optimize active focusing strategies. For
both correctness reward calculation and benchmark evalu-
ation, we employed the LLM-as-a-judge approach, specifi-
cally utilizing the Gemini-2.5-pro model. The training cor-
pus is composed of the proposed GroundedVQA training
set, combined with 3,000 items randomly sampled from
the FVQA training set. The RL stage was conducted for
2 epochs with a learning rate of 2e −6, a KL coefficient
β = 0.01, λ = 0.1 and a group size G = 8. All models
were trained on 8×A100 GPUs. All prompts employed are
available in the Appendix.
Baselines. To comprehensively evaluate the effectiveness
of both our proposed architecture and the trained model, we
categorize our comparisons into four distinct groups:
• Vanilla ReAct Baselines:
We utilize standard open-
source models (e.g., Qwen2.5-VL-7B) equipped with
web tools following the classic ReAct[20] paradigm. This
serves as the fundamental baseline to assess base model
capabilities without specialized training or architecture.
• ReFAct Architecture Validation: To isolate the contri-
bution of our proposed architecture, we equip standard
vanilla models (from the first category) with our ReFAct
framework. This comparison directly validates the archi-
tectural superiority of ReFAct over ReAct.
• RL-Trained Web Search Agents: We include state-
of-the-art open-source agents trained via reinforcement
learning. These represent the strongest open-source base-
lines for multimodal web search tasks and provide a direct
comparison to our trained ReFAct-7B model.
• Closed-source Models:
We also include top closed-
source models (GPT-5-mini, Gemini-2.5-flash) as upper-
bound references for current general capabilities.
Benchmarks. We utilize a diverse set of benchmarks to
evaluate different agent capabilities:
• GroundedVQA-Test: Our proposed benchmark, featur-
ing high visual noise and complex multi-step reasoning,
serving as the primary in-domain evaluation.

4.2. Main Results
Tab. 2 presents the comparative performance across all
benchmarks.
Among RL-trained open-source agents,
ReFAct-7B achieves decisive gains on the high-noise
GroundedVQA while maintaining strong adaptability on
low-noise benchmarks like SimpleVQA, demonstrating that
it does not over-process when explicit grounding is un-
necessary. However, its performance on general-purpose
benchmarks (e.g., SimpleVQA, LiveVQA) lags behind top
closed-source models like Gemini-2.5-flash. This discrep-
ancy reveals an inherent trade-off of the active visual fo-
cusing mechanism: while localizing regions effectively fil-
ters noise on GroundedVQA, tasks like LiveVQA require
holistic image comprehension to construct accurate retrieval
queries. The region-level focus of the Grounding tool may
reduce search query richness, leading to suboptimal re-
trieval on benchmarks where fine-grained grounding is un-
necessary.
A deeper analysis of the plug-and-play application of our
framework (models without RL training) reveals that its ef-
fectiveness is highly dependent on the base model’s intrinsic
capabilities. The ReFAct framework yields significant im-
provements for the Qwen series models; for instance, apply-
ing it to Qwen2.5-VL-72B provides a +0.111 absolute gain
on GroundedVQA Level-1. In sharp contrast, the frame-
work offers negligible or even negative gains for the eval-
uated closed-source models (Gemini-2.5-flash and GPT-5-
mini). We hypothesize this is because ReFAct leverages a
model’s existing grounding ability. The Qwen series, pos-
sessing strong base visual grounding, can successfully use
the tool to filter noise. Conversely, models with weaker in-
nate grounding fail to focus on the correct region, rendering
the active focusing mechanism ineffective.

• w/o Visual Focusing: Disabling the Ground tool causes

5. Conclusions
This paper introduces ReFAct, a novel framework designed
to overcome the critical challenge of contextual noise in
multimodal web environments by shifting agents from pas-
sive information consumption to active context manage-
ment.
Through synergistic Active Visual Focusing and
Active Memory Focusing mechanisms, ReFAct empowers
agents to dynamically filter visual clutter and retrieval over-
load, thereby maintaining a high-fidelity working memory
for complex reasoning.
We instantiated this architecture
in ReFAct-7B and validated it using our newly constructed
GroundedVQA benchmark, where it demonstrated signifi-
cant performance gains over existing open-source baselines
and competitiveness with top-tier proprietary models, par-
ticularly in high-noise regimes. Our work establishes ac-
tive focusing as a foundational requirement for robust mul-
timodal agents, paving the way for future extensions into
continuous data streams such as real-time video or audio
processing.
